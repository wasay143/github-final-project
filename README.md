# Simple Interest Calculator

## Description

This project is a simple interest calculator that calculates the simple interest based on the principal amount, annual interest rate, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Features

* Enter principal amount
* Enter interest rate
* Enter time period
* Calculate simple interest
* Simple and easy-to-use interface

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Use

1. Enter the principal amount.
2. Enter the interest rate.
3. Enter the time period.
4. Click the Calculate button.
5. The calculator will display the simple interest.
